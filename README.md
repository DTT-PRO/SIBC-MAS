# SIBC-MAS prompt archive

This repository contains the original prompt templates and documented runtime message assembly used by the LLM/VLM components described in the manuscript “SIBC-MAS: A Multimodal Multi-Agent System for Sodium-Ion Battery Cathodes.”

## Scope

- Prompt records P1–P13, including the P7a–P7c cross-modal branches.
- Runtime dynamic fields are represented by angle-bracketed labels.
- Multimodal content-item order, recorded runtime temperatures, and the controller stopping rule are documented.
- The controller executes no more than three Scientist–Critic verification rounds and summarizes any unresolved disagreement.
- No source code, research data, model weights, credentials, server addresses, or local filesystem paths are included.

## Files

- `prompts.md`: prompt templates and message-assembly details corresponding to the revised Supplementary Information.

## Version

This archive corresponds to the minor-revision prompt record prepared in September 2026.
